# X Загрузчик

Android-приложение для скачивания видео из постов X (Twitter).

## Как пользоваться
- В приложении X нажмите **Поделиться → X Загрузчик**, или скопируйте ссылку на пост и нажмите **Вставить** в приложении.
- Выберите качество — видео сохранится в `Movies/X/` и появится в галерее.

## Где взять APK
Каждый пуш в `main` собирает APK через GitHub Actions и выкладывает его в релиз **latest**
(вкладка Releases → `XDownloader.apk`).

## Как это работает
Ссылки на видео берутся из публичного syndication-API X (то же, что используют встраиваемые посты),
запасной источник — api.fxtwitter.com. Вход в аккаунт не нужен; приватные посты и посты 18+ без входа недоступны.
